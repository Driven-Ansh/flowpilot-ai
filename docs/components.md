# Frontend Component Documentation

## Shared & Layout Components

- **`Sidebar`**: Collapsible sidebar navigation featuring active route highlighting, company metadata badge, and animated group accordions.
- **`Header`**: Top application header with route title breadcrumbs, theme toggler, and avatar indicator.
- **`ThemeProvider`**: Context wrapper managing dark/light theme classes on `<html>`.
- **`KpiCard`**: Animated dashboard KPI card with gradient glow effects.
- **`ScoreRing`**: SVG circular progress ring rendering Feasibility, Impact, and ROI scores.
- **`TypingIndicator`**: Bouncing dot animation displayed during AI streaming responses.
- **`RoadmapItemCard`**: Phase item display card with effort indicators, ROI estimation badges, and recommended tool tags.

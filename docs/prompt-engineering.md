# Prompt Engineering Strategy

## Discovery System Prompt (`INTERVIEW_SYSTEM_PROMPT`)

- **Role**: Senior AI Automation Strategy Consultant.
- **Constraints**: Ask ONE question at a time, be empathetic, probe for hours/week spent, list software tools used, and keep responses under 150 words.

## Extraction System Prompt (`EXTRACTION_PROMPT`)

- **Role**: Senior Business Process Analyst.
- **Output Constraint**: Output strictly valid JSON conforming to the schema containing `processes`, `team_structure`, `current_tools`, `key_pain_points`, and `automation_maturity`.
